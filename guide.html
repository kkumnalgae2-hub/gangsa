EmailJS 문의 폼 설정 안내

이 문서 안의 값과 HTML 전체를 복사해 EmailJS와 Gmail 화면에 붙여넣으세요. 문서 열기·복사·체크리스트는 인터넷 없이도 동작합니다. 서비스 연결과 실제 발송에는 인터넷이 필요합니다.

웹페이지 코드는 준비되어 있습니다. 실제 메일 수신을 완료하려면 아래 서비스·템플릿 설정과 마지막 발송 확인을 해 주세요. 기존 ID의 템플릿이 있다면 새로 중복 생성하지 말고 해당 템플릿을 수정합니다.

STEP 1 · 계정과 Gmail 서비스 연결

화면에서 누를 위치

  1. EmailJS 대시보드에 로그인합니다.
  2. Email Services → Add New Service → Gmail → Connect Account에서 아래 Gmail 계정을 연결합니다. 이미 연결되어 있으면 기존 서비스를 엽니다.
  3. 서비스 설정의 Service ID를 확인하고 저장합니다.
  4. Account → General의 Public Key를 확인합니다. 코드에는 이미 아래 공개 키가 들어 있습니다.

STEP 2 · 접수 알림 템플릿

화면에서 누를 위치

  1. Email Templates에서 아래 ID가 있는지 확인합니다. 없으면 Create New Template을 누릅니다.
  2. Settings 탭에서 Template ID를 확인·수정하고 저장합니다.
  3. Content 탭 또는 편집 화면의 수신자·제목 항목에 아래 값을 입력합니다. 화면 버전에 따라 Settings에 표시될 수 있습니다.
  4. 본문 편집기 우측 상단 코드 보기(< >)로 HTML 모드를 열고, 아래 알림용 HTML 전체의 복사 버튼을 눌러 붙여넣은 뒤 Save 합니다. 코드 보기가 없으면 본문 편집 방식에서 HTML/Code Editor를 선택합니다.

STEP 4 · 구글 → 네이버 자동 전달

화면에서 누를 위치

  1. Gmail → 설정(톱니바퀴) → 모든 설정 보기 → 전달 및 POP/IMAP(또는 전달) → 전달 주소 추가를 누릅니다.
  2. 아래 네이버 주소를 등록합니다. 네이버로 온 확인 메일의 인증 링크를 직접 열어 승인합니다.
  3. Gmail로 돌아와 설정을 새로고침합니다. 전체 메일 전달 대신 문의만 전달하려면 아래 검색 조건으로 필터를 만듭니다.
  4. 검색창 오른쪽 검색 옵션 표시 → 조건 입력 → 필터 만들기 → 다음 주소로 전달 체크 → 네이버 주소 선택 → 필터 만들기를 누릅니다.

붙여넣을 값

설정 항목 / 화면 위치붙여넣을 값

kkumnalgae@naver.com
Gmail 검색 조건
to:kkumnalgae1@gmail.com subject:문의

EmailJS는 연결된 Gmail에서 같은 Gmail로 알림을 보냅니다. 자기발신 메일은 전달 필터가 예상대로 작동하지 않을 수 있습니다. 실제 테스트에서 네이버에 도착하지 않으면 STEP 2의 Bcc에 네이버 주소를 넣고 저장하세요. Bcc와 필터 전달을 동시에 켜면 중복 도착할 수 있습니다.

이 설정은 새로 수신하는 메일에 적용됩니다. 스팸함도 확인하세요.
